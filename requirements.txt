# AI Trading Bot (Advanced)

A production-style AI trading bot starter for crypto and stock markets with real market data, risk controls, ML-based signal generation, and a local dashboard.

## Features

- Binance and Alpha Vantage integration for live market data
- Technical features: SMA, EMA, RSI, MACD, volatility, Bollinger
- Logistic-regression ML signal engine
- Risk management and position sizing
- Backtesting workflow
- FastAPI endpoints
- Local Streamlit dashboard
- Alert webhook support
- Portfolio service prototype

## Tech stack

- Python 3.11+
- FastAPI
- Streamlit
- SQLAlchemy
- Pandas / NumPy
- scikit-learn
- httpx

## Installation

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Environment variables

Create a `.env` file with:

```env
DATABASE_URL=sqlite:///./trading.db
BINANCE_API_KEY=
BINANCE_API_SECRET=
ALPHA_VANTAGE_API_KEY=your_key_here
```

## Run the API

```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

## Run the dashboard

```bash
streamlit run dashboard.py
```

## Example API calls

```bash
curl "http://localhost:8000/api/market/analyze?symbol=BTCUSDT&market=crypto&interval=1h&limit=250&account_balance=10000"
curl "http://localhost:8000/api/backtest?symbol=BTCUSDT&market=crypto&interval=1h&limit=250&initial_capital=10000"
curl "http://localhost:8000/api/portfolio"
curl -X POST "http://localhost:8000/api/alerts/test?message=Test+alert"
```
